# LLcad operators

Generated by scripts/gen-operator-docs.ts from schemas/operator-registry.json (registry 5fc91ce1953d, 57 operators; 57 with registry semantics, others from the hand-verified worker table). Do not edit by hand.

## Conventions for every operator

- Units: lengths mm, angles deg, scalars unit "1"; each parameter is {"value": "<decimal string>", "unit": ...}.
- Every feature is built in its `local_frame` (a structure frame, default world); inputs from other frames are transformed automatically. Use frames, not transform chains.
- `refs` is the allowed number of `depends_on` inputs. Booleans take at most 16 inputs: stage bigger ones as a tree.
- precision_cad outputs must be closed solids: curves, profiles and sheets are construction inputs only.
- <=64 operations per patch; unique idempotency_key per attempt; structure ids (parts, frames) must differ from feature ids.
- Examples are minimal add_feature operations; a check mark means the example parses with the live IR schema.
